## J. LIFF routing (บั๊กที่เคยเจอ)

> เคยพัง: query หายหลัง OAuth → ตกไปหน้าสร้างบิล + popup สลิปทับ

| # | ทำ | คาดหวัง |
|--|--|--|
| J1 | Logout LINE / บัญชีใหม่ → กด ✈️ จดบิลทริป (ผ่าน OAuth) | ยังเข้าหน้า**ทริป** ไม่ใช่หน้าสร้างบิล |
| J2 | เปิด `?view=trip&groupId=X&debug=1` → console | `[main] rawView: trip view: trip` |
| J3 | console บรรทัด `[visible]` | มีแค่ `["trip-view", "app-version-footer..."]` — **ไม่มี** `slip-modal` |
| J4 | Local Storage | key `billbot.nav` = `{"view":"trip","groupId":"...","_t":<ts>}` |
| J5 | ทิ้งไว้ > 10 นาที แล้วเปิดสดๆ ไม่มี query | ได้หน้าสร้างบิล (intent หมดอายุ ถูกต้อง) |
| J6 | เปิดลิงก์ทริปที่แชร์ (`?view=trip&tripId=T1`) | เข้าหน้าจัดการทริปนั้นตรงๆ |
| J7 | ลิงก์บิลเดิม (`?view=detail&billId=B1`) | ยังเข้าหน้ารายละเอียดบิลได้ |
| J8 | Deploy ใหม่ → เปิดหน้า | `<script src="app.js?v=<hash ใหม่>">` — JS ใหม่ทำงานทันที ไม่ต้องล้าง cache |
